Kasirku

Aplikasi kasir dengan database tersimpan di Google Drive-mu sendiri

Menghubungkan Google Drive...

Kasirku sedang otomatis meminta izin akses ke Google Drive-mu. Jika jendela login tidak muncul (biasanya karena diblokir browser), klik tombol di bawah ini.

Kenapa perlu izin Google Drive?

Kasirku memakai Google Drive-mu sebagai database, bukan server pihak ketiga. Setelah klik "Hubungkan Google Drive", akan muncul jendela login Google — pilih akunmu, lalu izinkan akses. Karena aplikasi masih tahap testing, mungkin muncul peringatan "Google belum memverifikasi aplikasi ini" — klik Advanced/Lanjutan → Buka Kasirku (unsafe) untuk melanjutkan. Pastikan email akun Google-mu sudah didaftarkan sebagai Test user di Google Cloud Console.
